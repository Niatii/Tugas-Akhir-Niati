### Authentication
POST   http://localhost:3000/api/v1/auth/login
Content-Type: application/json
{
  "email": "user@example.com",
  "password": "password"
}

POST   http://localhost:3000/api/v1/auth/register
Content-Type: application/json
{
  "email": "user@example.com",
  "password": "password",
  "name": "Jane Doe",
  "role": 1
}

GET    http://localhost:3000/api/v1/auth/profile


### Users
GET    http://localhost:3000/api/v1/users

GET    http://localhost:3000/api/v1/users/:id

POST   http://localhost:3000/api/v1/users/:id/image
Content-Type: multipart/form-data
Body: form-data dengan field `image` (file)

PUT    http://localhost:3000/api/v1/users/change-password
Content-Type: application/json
{
  "old_password": "password",
  "new_password": "newpassword",
  "new_password_confirmation": "newpassword"
}

PUT    http://localhost:3000/api/v1/users
Content-Type: application/json
{
  "name": "Jane Doe",
  "email": "jane@example.com",
  "username": "janedoe",
  "role": 1
}

DELETE http://localhost:3000/api/v1/users/:id
